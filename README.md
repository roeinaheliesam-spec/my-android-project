# Android Class Hub

پروژه Android Studio با Kotlin و Jetpack Compose برای دوره Android Fundamentals.

## تکالیف اجباری

### تکلیف ۱: سه کنترل
در صفحه «تکلیف ۱» هر سه کنترل زیر به‌صورت واقعی و تعاملی پیاده‌سازی شده‌اند:

- CheckBox: تغییر وضعیت فعال/غیرفعال
- RadioButton: انتخاب یکی از سه گزینه
- Switch: روشن/خاموش کردن وضعیت
- وضعیت هر سه کنترل در پایین صفحه نمایش داده می‌شود.

کد اصلی در `app/src/main/java/com/example/androidclasshub/MainActivity.kt` قرار دارد.

### تکلیف ۲: Wireless Debugging
این مورد تنظیم دستگاه و Android Studio است و کد Kotlin ندارد. مراحل انجام آن داخل صفحه «تکلیف ۲» برنامه نوشته شده است:

1. گوشی و کامپیوتر روی یک Wi‑Fi باشند.
2. Developer options را فعال کنید.
3. Wireless debugging را روشن کنید.
4. در Android Studio از Device Manager گزینه Pair using Wi‑Fi را انتخاب کنید.
5. کد Pairing گوشی را وارد کنید.
6. پس از Pair شدن، گوشی را برای Run انتخاب کنید.

## اجرا
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را کامل کنید.
3. گوشی یا Emulator را انتخاب کنید.
4. Run را بزنید.
