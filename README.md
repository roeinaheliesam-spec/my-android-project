# Android Class Hub

پروژه نمونه Android Studio با Kotlin و Jetpack Compose برای تبدیل محتوای دوره Android Fundamentals به یک اپلیکیشن.

## وضعیت
- جلسات ۱ تا ۴ در اپ به‌صورت محتوای آماده نمایش داده می‌شوند.
- جلسات ۵ تا ۱۰ به‌صورت مسیر آینده نمایش داده می‌شوند.
- معماری پروژه طوری نوشته شده که بعداً می‌توان Navigation، جست‌وجو، علاقه‌مندی، تمرین و دیتابیس را اضافه کرد.

## اجرا
1. پوشه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. Emulator یا گوشی متصل کنید.
4. Run را بزنید.

محتوای جلسات بر اساس فایل‌های HTML ارائه‌شده در گفتگو تنظیم شده است.
